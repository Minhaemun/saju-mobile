# 별담 운세

모바일 중심으로 만든 정적 사주·운세 리포트 실습 서비스입니다. HTML, CSS, JavaScript만 사용하며 GitHub Pages 하위 경로에서 동작합니다.

## 사용 방법

1. 첫 화면에서 시작하기를 누르고 이메일과 6자 이상 비밀번호로 가입합니다.
2. 이메일 확인 없이 바로 로그인하려면 Supabase Auth 설정에서 이메일 확인(Confirm email)을 꺼야 합니다. 현재 설정은 Supabase 대시보드에서 확인하세요.
3. 생년월일과 양력/음력, 윤달 여부, 정확한 출생 시각 또는 시각 모름을 입력합니다.
4. 리포트에서 일간·월간·연간 탭, 날짜 이동, 상세 항목 접기/펼치기와 실천 체크리스트를 사용할 수 있습니다.

## 계산 기준과 범위

- 기준 지역은 한국, 시간은 한국 표준시(KST, UTC+9)입니다. 경도에 따른 진태양시 보정이나 과거 표준시 변경 보정은 하지 않습니다.
- 출생 입력 지원 범위는 1900-01-31부터 2050-12-31까지입니다. 입력한 음력 날짜는 라이브러리 달력 변환 결과로 검증하며, 윤달은 해당 연·월에 존재하는 경우에만 처리합니다.
- 연주는 입춘 절입 시각, 월주는 절기 절입 시각 기준으로 계산합니다. 일주와 시주는 입력한 KST 시각을 라이브러리에 전달하고, 자정 기준의 일자 경계(야자시를 다음 날로 보지 않는 설정)를 사용합니다.
- 출생 시각을 모르면 시주를 확인 불가로 표시합니다. 절기 교체 시각 전후 출생은 정확한 출생 시각이 있어도 입력 오차에 따라 경계 판정이 달라질 수 있습니다.
- 일간은 선택한 양력 날짜의 간지를 사용합니다. 월간 대표 날짜는 해당 월 15일, 연간 대표 날짜는 해당 연도 7월 1일입니다. 절기 기준 월·연 간지는 대표 시점의 값이며 양력 기간 전체의 같은 간지가 계속된다는 뜻이 아닙니다.
- 오행은 연·월·일·시주의 천간과 지지에 각각 대표 오행을 하나씩 부여해 단순 집계합니다. 시각 미상일 때는 확인 가능한 6글자만 집계합니다. 지장간·대운·용신·신강·신약·신살·합충은 제공하지 않습니다.
- 해석은 출생 일간과 기간 대표 간지 천간 사이 십신 관계를 이용한 결정적 규칙 기반 참고 문구입니다. 교육·오락용 전통 해석이며 건강 진단, 투자 조언, 미래의 확정이나 수익 보장을 제공하지 않습니다.

## 보안과 데이터

- 출생일, 시각, 별명, 운세 결과는 서버로 보내지 않으며 브라우저 저장소에도 저장하지 않습니다.
- 이메일과 비밀번호는 Supabase Auth에서 처리합니다. 소스에 포함된 Supabase 값은 공개 URL과 publishable key뿐이며 관리자 키는 없습니다.
- 로그아웃 때 메모리의 운세 상태를 지웁니다. 인증 세션은 Supabase JS 표준 세션 저장·갱신 기능을 사용합니다.

## 배포

정적 파일을 저장소 루트에 두고 GitHub Pages를 `main` 브랜치 / root 경로로 설정합니다. Supabase Auth의 Site URL을 `https://minhaemun.github.io/saju-mobile/`로, Redirect URL도 같은 URL로 지정해야 합니다.
